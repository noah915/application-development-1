## 📋 API ENDPOINTS (16 Total)

### Public Endpoints
```
GET  /items
GET  /items/:id
GET  /items/category/:category
POST /auth/register
POST /auth/login
```

### User Endpoints (Login Required)
```
POST   /auth/logout
GET    /auth/me
POST   /items
PUT    /items/:id          (owner/admin only)
DELETE /items/:id          (owner/admin only)
```

### Admin Endpoints (Admin Only)
```
GET    /admin/users
PUT    /admin/users/:userId/role
GET    /admin/users/:userId/items
DELETE /admin/items/:itemId
GET    /admin/statistics
```
